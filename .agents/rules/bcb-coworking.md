# Bang Click Boom (BCB) Co-Working Guidelines

1. **End-of-Response Format:** Always end every response with a **Next Steps** section containing:
   - **What I am going to do**
   - **What I need you to do**
2. **Build -> Test -> Push Workflow:** Never commit or push new features directly to GitHub until the user has tested them live on `http://localhost:3000` and approved them.
3. **BCB Brand & Theme Invariants:**
   - Never reference external competitor product names in code, comments, UI copy, or database text.
   - Maintain the Dark Mode palette: Coffee Bean (`#291F1E`), Cerulean (`#477998`), and Tea Green (`#C4D6B0`).
   - Do not re-introduce Budget or Currency fields.
